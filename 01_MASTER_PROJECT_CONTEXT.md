# Master Project Context

## Product Vision
Build a real commercial global household finance and shopping platform for individuals, couples, families, roommates, OFWs, migrant workers, expats, and cross-border households.

The product is not just an expense tracker.

Its long-term differentiation is:

**Household finance + shared collaboration + shopping intelligence + retailer pricing/coupons + international multi-currency support.**

## Core Product Promise
> One household, one synchronized financial picture, even when members use different devices, currencies, retailers, addresses, branches, or live in different countries.

## Target Platforms
The same account and household data must be usable and synchronized on:
- iPhone
- iPad
- Android phones
- Android tablets
- Web browsers
- Windows PC via web/PWA
- macOS via web/PWA

A dedicated Windows `.exe` or native macOS app is not required for MVP. Use installable web/PWA first.

## Cloud Synchronization
Cloud data is authoritative.

Example:
- Wife adds `Milk` on Android.
- Husband sees it on iPhone or PC.
- Husband marks it purchased.
- Wife's device reflects the change.

A lost/replaced phone must not mean lost household data. After secure authentication, a supported device should regain access to synchronized data.

## Long-Term Functional Areas
1. Authentication and security
2. Household membership and permissions
3. Income
4. Expenses
5. Transactions
6. Budgets
7. Bills / recurring obligations
8. Debt management
9. Savings goals
10. Shared grocery/shopping lists
11. Retail product catalog
12. Branch-specific retailer pricing
13. Coupons / promotions / loyalty pricing
14. Basket price comparison
15. Multi-currency households
16. FX history/snapshots
17. Cross-border / OFW household tracking
18. Premium subscriptions
19. Merchant/retailer integrations later

## Product Principles
- Global from day one.
- Mobile + web from one primary codebase.
- Security by database policy, not just UI logic.
- Money calculations must be exact.
- Retail data must be authorized/licensed/permitted.
- Store/branch matters.
- Price freshness must be visible.
- Subscription pricing is regional, not USD-only.
- MVP simplicity is more important than premature enterprise complexity.
